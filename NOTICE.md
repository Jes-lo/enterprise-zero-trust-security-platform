# Notice

This repository contains an independently designed portfolio project
demonstrating enterprise Zero Trust security engineering concepts in a
controlled Microsoft 365 laboratory environment.

## Independence

The project is not an official Microsoft project.

It is not sponsored, endorsed, certified, or maintained by Microsoft.

Architecture, policy models, automation, documentation, test scenarios,
and diagrams created specifically for this project are independently
authored.

## Laboratory environment

All demonstrations and tests must use environments that the project owner
is authorized to administer.

The project must not contain:

- Production credentials
- Production customer data
- Employer-confidential information
- Real employee information
- Authentication tokens
- Private keys
- Unsanitized tenant identifiers
- Unauthorized security-test results

Synthetic or sanitized data must be used for public evidence.

## External references

Official vendor documentation may be consulted to understand supported
product behavior, APIs, configuration requirements, and security
capabilities.

External material must not be copied into this repository unless its
license explicitly permits that use and the required attribution is
provided.
